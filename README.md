# OCR_Balance

บริการอ่านตารางจาก**บัญชีและรายงานยาเสพติดให้โทษ/วัตถุออกฤทธิ์** ที่ส่งมาเป็น PDF
— อ่านเฉพาะข้อมูลในตาราง แล้วคืนค่าออกมาเป็น JSON และไฟล์ Excel

รองรับทั้งไฟล์ที่**พิมพ์มา** (อ่านข้อความที่ฝังในไฟล์ได้ตรง ๆ แม่นมาก) และ
ไฟล์ที่**กรอกด้วยลายมือแล้วสแกน** (ต้องผ่าน OCR แม่นน้อยกว่ามาก)
ระบบเลือกเองรายหน้าและบอกไว้ใน `page_summary[].source`

ขอบเขตของบริการนี้คือ**ตัวระบบ OCR อย่างเดียว** — รับไฟล์ อ่าน คืนค่า
ไม่เปรียบเทียบกับฐานข้อมูลใด ไม่ตัดสินใจอะไรแทนผู้เรียก และไม่มีคิวงาน
ส่วนที่เหลือ (frontend, business logic, deployment) อยู่นอกโปรเจกต์นี้

## เอกสารที่รองรับ

**ประเภท ๒** (พิมพ์ — ไฟล์มี text layer):

| แบบฟอร์ม | ชื่อเต็ม | คอลัมน์ |
| --- | --- | --- |
| บ.ย.ส. ๒/ว.จ. ๒-จ๑ | บัญชีจำหน่ายยาเสพติดให้โทษ/วัตถุออกฤทธิ์ในประเภท ๒ | 11 |
| ร.ย.ส. ๒/ว.จ. ๒-จ๑ | รายงานเกี่ยวกับการดำเนินกิจการจำหน่ายฯ ในประเภท ๒ | 12 |

**ประเภท ๓/๔** (เขียนด้วยลายมือ — ต้อง OCR):

| แบบฟอร์ม | ชื่อเต็ม | คอลัมน์ |
| --- | --- | --- |
| ร.ว.จ ๗/๔ | รายงานผลการดำเนินกิจการเกี่ยวกับวัตถุออกฤทธิ์ฯ | 12 |
| บ.ว.จ ๗/๔-ขพ | บัญชีจำหน่ายวัตถุออกฤทธิ์ฯ | 12 |
| ร.ค.-๔ | รายงานเกี่ยวกับการมีไว้ในครอบครองวัตถุออกฤทธิ์ฯ | 11 |

## เริ่มใช้งาน

```powershell
# 1. venv + dependencies + .env + CA bundle (Python 3.10-3.12 เท่านั้น;
#    paddlepaddle 2.6.2 ยังไม่มี wheel สำหรับ 3.13)
.\scripts\setup.ps1 -Dev

# 2. ตั้งค่า DB_* ใน .env แล้วสร้างตาราง
.\scripts\migrate.ps1

# 3. รัน
.\scripts\local-run.ps1          # http://localhost:3004
```

ถ้ายังไม่มี PostgreSQL บนเครื่อง ใช้ SQLite รันดูก่อนได้เลย:

```powershell
.\scripts\migrate.ps1 -Sqlite
.\scripts\local-run.ps1 -Sqlite
```

ยิงเอกสารเข้าไป:

```bash
curl -X POST http://localhost:3004/api/v1/balance/documents \
  -F "file=@ledger.pdf" -F "uploaded_by=go-backend"
```

เติม `?pretty` ต่อท้าย URL ถ้าจะเปิดอ่านเอง (ปริยายเป็นบรรทัดเดียวสำหรับโปรแกรม)

ได้ JSON กลับมาโดยที่ `entries` คือ **12 คอลัมน์ตาม `ฟอแมทตาราง OCR.xlsx`**
(ชื่อคีย์และลำดับตรงกับหัวคอลัมน์ในไฟล์ Excel ทุกตัวอักษร รวมถึงการขึ้นบรรทัดใหม่)
ไม่มีข้อมูลรายแถวอย่างอื่นส่งมาด้วย — `review_count` บอกจำนวนแถวที่ไม่มั่นใจ
และไฟล์ Excel ลงสีแถวพวกนั้นไว้

สัญญาการเรียกใช้ทั้งหมดอยู่ที่ [docs/BALANCE_API.md](docs/BALANCE_API.md)

## ข้อมูลมาจากไหน — ตัวแปรสำคัญที่สุดของความแม่น

ระบบเลือกแหล่งข้อมูลเองรายหน้า และบอกไว้ใน `page_summary[].source`:

| source | เมื่อไหร่ | ความแม่น |
| --- | --- | --- |
| `TEXT_LAYER` | ไฟล์มีข้อความฝังอยู่ (PDF ที่พิมพ์มา หรือสแกนที่ผ่าน OCR มาแล้ว) | **สูงมาก รวมถึงภาษาไทย** |
| `OCR` | สแกนล้วน เช่นฟอร์มที่กรอกด้วยลายมือ | ต่ำ และ**อ่านภาษาไทยไม่ได้เลย** |

วัดจาก `Sample.pdf` (4 หน้า, 18 แถวจริง, ใช้ text layer):

| | |
| --- | --- |
| ระบุชนิดฟอร์มถูก | 4/4 หน้า |
| จำนวนแถว | **18/18** |
| ตัวเลข ยกมา/รับ/จ่าย/คงเหลือ ถูก | **97%** (70/72) |
| ภาษาไทย (ชื่อผู้รับยา, เลขบัตร) | **อ่านได้ถูกต้อง** |
| แถวที่ต้องตรวจทาน | **2/18** |
| เวลา | **~0.5 วินาที/หน้า** |

วัดจากเอกสารลายมือ (8 หน้า, 45 แถวจริง, ต้อง OCR):

| | |
| --- | --- |
| ระบุชนิดฟอร์มถูก | 8/8 หน้า |
| จำนวนแถว | **45/45 ตรงทุกหน้า** |
| ตัวเลขถูก | 81% |
| วันที่ถูก | 36% |
| ภาษาไทย | **อ่านไม่ได้** — ดู [docs/OCR_THAI.md](docs/OCR_THAI.md) |
| เวลา | ~18 วินาที/หน้า |

**ความต่างนี้ไม่ใช่เรื่องการจูน** — ไฟล์ที่มี text layer ไม่ต้องเดาอะไรเลย
ส่วนลายมือต้องผ่าน PaddleOCR ซึ่งไม่มีโมเดลภาษาไทย

## วิธีที่ระบบอ่านตาราง

ฟอร์มพวกนี้เป็นตารางพิมพ์ที่กรอกด้วยลายมือ จึงใช้วิธีคนละแบบกับ parser เดิม:

1. **แก้หน้าเอียง + หาเส้นตาราง** (`workers/grid_detector.py`)
   ลายมือเขียนล้นเส้นประจำ การเดาคอลัมน์จากตำแหน่งข้อความจึงพลาด
   ระบบจึงตรวจจับ**เส้นแนวตั้งที่พิมพ์ไว้**ด้วย OpenCV เพื่อให้ได้ขอบคอลัมน์จริง
   (สแกนเอียงแค่ 1 องศา ก็ทำให้หาเส้นยาว 2000 px ไม่เจอ จึงต้อง deskew ก่อน)
2. **ระบุชนิดฟอร์มจากสัดส่วนคอลัมน์** (`workers/form_layout.py`)
   อ่านหัวตารางไม่ได้เพราะเป็นภาษาไทย จึงใช้เรขาคณิตแทน — แม่น 8/8 หน้า
3. **แบ่งแถวจากช่องตัวเลข** (`workers/balance_parser.py`)
   ฟอร์มพวกนี้**ไม่มีเส้นคั่นระหว่างแถวข้อมูล** และชื่อยามักตัดขึ้นบรรทัดใหม่
   ระบบจึงยึดช่อง ยอดยกมา/รับ/จ่าย/คงเหลือ ซึ่งมีหนึ่งค่าต่อแถวเสมอ
   เป็นตัวกำหนดแถว แล้วค่อยดึงช่องอื่นเข้ามา
   วิธีนี้ทำให้หัวตารางที่พิมพ์มาหลุดออกไปเองโดยไม่ต้องอ่านมัน
4. **ทำความสะอาดค่า + ตรวจสอบ** (`workers/balance_normalizer.py`)
   รวมถึงการตรวจ `ยอดยกมา + รับ - จ่าย = คงเหลือ` ซึ่งเป็นการยืนยันตัวเลข
   ด้วยกันเองโดยไม่ต้องพึ่งข้อมูลภายนอก

## โครงสร้าง

```text
apps/
  balance/               model, API, บริการของเอกสารชุดนี้
  core/                  CORS, error envelope, /health /ready
workers/
  grid_detector.py       deskew + หาเส้นตาราง
  form_layout.py         ทะเบียนฟอร์ม 3 แบบ + การระบุชนิด
  balance_parser.py      หน้า -> แถว
  balance_normalizer.py  ทำความสะอาดวันที่/จำนวน/เลขรุ่น
  balance_pipeline.py    PDF ทั้งไฟล์ -> แถว
  balance_export.py      ไฟล์ Excel
  ocr_engine.py          PaddleOCR + preprocessing (ใช้เมื่อไม่มี text layer)
  pdf_extractor.py       ตรวจไฟล์ PDF + อ่าน text layer ที่ฝังมาในไฟล์
config/settings/
  base.py                ค่ากลาง
  development.py         PostgreSQL ตาม .env
  production.py          PostgreSQL, secrets จาก environment
  local_sqlite.py        SQLite เป็นไฟล์ สำหรับเครื่องที่ไม่มี PostgreSQL
  sqlite.py              SQLite in-memory สำหรับเทส
scripts/
  setup.ps1 migrate.ps1 local-run.ps1 test.ps1
  setup_certs.py         แก้ปัญหา TLS ตอนโหลดโมเดล
docs/
  BALANCE_API.md         สัญญา API
  OCR_THAI.md            ข้อจำกัดภาษาไทย
```

เส้นทางทั้งหมดที่เปิดให้เรียก: `/api/v1/balance/*`, `/health`, `/ready`
ไม่มีอย่างอื่น

## ตั้งค่าที่เกี่ยวข้อง

| ตัวแปร | ปริยาย | |
| --- | --- | --- |
| `OCR_LANGUAGE` | `latin` | **ห้ามใส่ `th`** - PaddleOCR 2.9.1 จะ assert ทิ้ง |
| `OCR_RENDER_DPI` | `200` | ค่าที่ใช้ปรับจูนการหาเส้นตาราง เปลี่ยนแล้วต้องตรวจ tolerance ใหม่ |
| `REQUESTS_CA_BUNDLE` | `certs/ca-bundle.pem` | สร้างด้วย `scripts/setup_certs.py` |
| `DOCUMENT_ROOT` | `./data` | ไฟล์ที่อัปโหลดลงที่ `data/input/` |
| `DB_*` | PostgreSQL | ชี้ไปที่เซิร์ฟเวอร์ไหนก็ได้ ระบบใช้แค่ตาราง `balance_*` กับ `django_*` |

## ส่งต่องาน

ระบบนี้สร้างตารางของตัวเองแค่ `balance_document`, `balance_entry` และ
`django_migrations` จึงแชร์เซิร์ฟเวอร์ PostgreSQL กับระบบอื่นได้โดยไม่ชนกัน
คนรับงานแค่ตั้ง `DB_*` ใน `.env` ให้ชี้มาที่เซิร์ฟเวอร์ของตัวเอง แล้วรัน
`migrate` ไม่ต้องแก้โค้ด
